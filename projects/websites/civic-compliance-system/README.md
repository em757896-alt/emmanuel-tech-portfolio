# Civic Compliance System

> A secure, responsive, and user-centric web platform designed to strengthen civic participation, support Public Benefit Organization (PBO) compliance, and enhance civic space monitoring in Kenya.

**🌐 Live Demo:** https://civiccompliancehub.gt.tc/

---

## Overview

The Civic Compliance System is a comprehensive web application developed to support civic organizations, Public Benefit Organizations (PBOs), legal practitioners, administrators, and the public by providing a centralized platform for legal awareness, compliance guidance, civic space monitoring, and structured reporting.

The platform promotes transparency, accountability, and easier access to information regarding the Public Benefit Organizations (PBO) Act while enabling organizations to monitor compliance, report civic incidents, and access educational resources.

# Installation

Clone the repository

```bash
git clone https://github.com/em757896-alt/emmanuel-tech-portfolio.git
```

Navigate into the project

```bash
cd projects/websites/civic-compliance-system
```

Move the project into your web server directory (XAMPP/WAMP/Laragon)

Example:

```
C:\xampp\htdocs\
```

Create the required MySQL database.

Import the provided SQL database.

Configure your database credentials.

Start Apache and MySQL.

Visit:

```
http://localhost/civic-compliance-system/
```
